# unity-mcp

Unity Editor automation and MCP integration.

## Description

The /unity-mcp command provides a diagnostic and setup helper for the Unity MCP bridge. It checks for a running Unity instance, verifies the MCP server status, and lists available Unity Editor tools.

## Usage

```markdown
/unity-mcp status
```

## Features

- **📡 Connection Audit**: Verifies the bridge between the assistant and Unity.
- **🛠️ Tool Inventory**: Lists active Unity Editor tools (Scene, Asset, Profiler).
- **📚 Doc Lookup**: Integrated `/unity-docs` for instant ScriptReference access.
- **🏗️ Build Control**: Quick access to `/manage-build` commands.
