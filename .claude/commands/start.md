# start

Initialize the Gaming Studio workspace and hierarchy.

## Description

The /start command is the entry point for the Game Studio workflow. It analyzes your current project state (concept, draft, existing work) and initializes the 49-agent roster and coordination hierarchy.

## Usage

```markdown
/start
```

## Features

- **📊 Stage Detection**: Automatically identifies if you are in Concept, Architecture, or Production.
- **🏗️ Hierarchy Init**: Configures Directors, Leads, and Specialists.
- **🗺️ Workflow Pathing**: Generates a roadmap for the next 3 milestones.
