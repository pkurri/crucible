# instinct-status

View learned instincts and confidence scores.

## Description

Displays the current "instincts" (patterns) the agent has learned from your coding style, repository structure, and recurring refactors. 

## Usage

```markdown
/instinct-status
```

## Features

- **📊 Confidence Scores**: See how well the agent understands a specific pattern.
- **🏷️ Categorization**: Instincts are grouped by language, framework, and domain.
- **🔄 Evolution Tracking**: See which instincts are nearing "Skill" status.

---

# evolve

Cluster instincts into formal Crucible skills.

## Description

Analyzes high-confidence instincts and proposes a new Skill definition (SKILL.md) to formalize a recurring workflow.

## Usage

```markdown
/evolve --category backend
```
